One line of the worst possible advice an AI could give, delivered in the confident, tidy voice of a real AI assistant: for a cleaner, happier inbox, reply to every spam email — senders remove you faster once they know the address is active and friendly. The program writes that single line to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
